- about-us.html — about
- contact-us.html — contact
- services.html — monthly Internet and combo plans

## Before public launch
1. Verify business address PIN, contact email, proprietor/legal name and policy wording.
2. Confirm actual service details, recharge terms, applicable taxes and HDFC PG requirements.
3. Do not add passwords, API keys or customer data to this repository.
4. Keep existing `portal.gcinfo.in` and `myaccount.gcinfo.in` DNS records unchanged.
